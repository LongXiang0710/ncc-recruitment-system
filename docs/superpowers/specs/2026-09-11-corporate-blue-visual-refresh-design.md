# 南化建招聘管理系统企业蓝视觉改版设计

## 目标

在不改变现有业务功能、字段、数据和操作结果的前提下，将全站统一为正式稳重的企业蓝风格，提高视觉层次、信息辨识度和长期办公使用的舒适度。

## 改版范围

覆盖管理后台、登录页、招聘总览、全部数据列表、查看与编辑弹窗、简历投递页、批量导入入口、二维码展示及打印页面。现有菜单顺序、表格字段、按钮功能、分页、导入导出、Dify 识别和人才入库流程保持不变。

## 视觉方向

- 左侧导航使用深海军蓝背景，当前菜单使用明亮企业蓝高亮，普通菜单保持清晰的浅色文字和图标。
- 页面背景使用极浅蓝灰色，主体内容使用白色卡片，形成稳定清晰的层次。
- 主色采用企业蓝，辅以深蓝文字、浅蓝交互背景、绿色成功状态、橙色提醒状态和红色危险操作。
- 卡片、表格、表单和弹窗使用统一圆角、边框和克制的阴影，不使用夸张渐变或装饰动画。
- 字号、行高、留白和控件高度形成统一规范，兼顾阅读舒适度与办公信息密度。

## 页面布局

### 管理后台

侧边栏保持固定布局，强化品牌区、菜单分组和当前页面状态。顶部栏降低视觉重量，突出账号入口。页面标题、说明和页面级操作形成稳定的左右结构。

招聘总览使用企业蓝欢迎区、数据卡片和分组面板。数据列表保持现有表格结构，改善表头、悬停反馈、状态标签、选择框、操作按钮和分页的视觉层级。工具栏仍位于搜索框下方并保持一排排列；屏幕不足时允许合理换行。

### 表单与弹窗

统一输入框、下拉框、日期控件、附件上传、经历子表和错误提示样式。弹窗继续使用右上角悬浮关闭按钮，正文与底部操作区层次清楚。危险操作与主要保存操作有明确颜色区别。

### 公开页面

登录页、简历投递页和批量导入入口共用同一品牌视觉。公开表单减少干扰，突出填写内容、附件选择和提交按钮。手机端保持单列布局和足够的触控尺寸。

### 二维码

保留当前简洁二维码内容和公司名称，统一卡片背景、边距、标题及下载按钮，使二维码能够直接用于招聘传单，同时确保二维码主体尺寸和安全留白不受视觉装饰影响。

## 代码组织

新增独立主题样式文件 `web/corporate-theme.css`，在现有基础样式之后加载。视觉覆盖集中维护，不把业务逻辑写入主题文件。只有在 CSS 无法可靠定位时，才在现有 HTML 模板中增加语义类名，不改变事件处理或数据流。

## 响应式与兼容性

重点验证常用桌面宽度，并检查 1150px 和 760px 以下的现有响应式断点。表格继续支持横向滚动，移动端导航、公开表单和弹窗不得溢出屏幕。保持键盘焦点、禁用状态、错误状态和文字对比度清晰可见。

## 验收标准

- 全站呈现一致的正式企业蓝风格。
- 所有现有页面、按钮、字段和业务流程仍可使用。
- 工具栏、表格、分页、弹窗和公开表单在桌面端无明显错位。
- 手机宽度下导航、表单和弹窗可正常阅读和操作。
- 二维码可扫描，附件预览和下载不受影响。
- 完整自动化测试全部通过，浏览器无新增脚本错误。
- 服务重新启动后仍使用现有地址 `http://172.16.30.81:8116/`。

## 不在本次范围

不新增业务模块，不调整数据库结构，不改动字段名称，不改变菜单与操作流程，不引入第三方前端框架，不替换当前 Dify 或附件处理逻辑，也不使用新的公司标志图片。
